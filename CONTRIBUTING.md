# Kontribusi

Boleh bantu, kecil pun tidak apa-apa.

1. Fork repo ini, buat branch dari `main`.
2. Build dulu: `./gradlew assembleDebug` (JDK 17, Android SDK 34).
3. Jalankan tes: `./gradlew testDebugUnitTest`.
4. Buka pull request dengan penjelasan singkat apa yang berubah.

Cari yang cocok di issue berlabel `good first issue`. Kalau ada soal yang salah, tulis nomor soal dan jawaban yang benar.
